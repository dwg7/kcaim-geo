- status: verified

札幌市の図書館(13施設)を、札幌市オープンデータの「札幌市公共施設一覧」から書き起こした。元データは、札幌市(一般会計)が保有する公共施設等(建物)の一覧で、令和7年3月31日時点の情報。ファイルは `011006publicfacility.xlsx`(867施設、106列)。幼稚園、学校、市営住宅、企業会計の施設は含まれない。

ここでいう「図書館」は、一覧の末尾にある、中央図書館運営企画課が所管する13施設(中央図書館、中央図書館大通カウンター、札幌市図書・情報館、新琴似・元町・東札幌・厚別・西岡・清田・澄川・山の手・曙の各図書館、えほん図書館)に限った。地区センターや児童会館などに併設された図書室は、図書館の列に数字があるが、図書館には含めていない(`/open-questions/sapporo-libraries`)。

元データには座標の列がない。所在地(住所)だけがあり、位置は住所から求めた(各 `/places/` の踏み跡を参照)。

出典: 札幌市オープンデータ「[札幌市公共施設一覧](https://ckan.pf-sapporo.jp/dataset/public_facility)」(クリエイティブ・コモンズ 表示 4.0 国際、CC BY 4.0。2026-10-31 参照)

# /rules/sapporo-library-budget-columns
- status: normative
- updated: 2026-10-31

元データの歳入・歳出の列を、図書館ごとに比べてはいけない。元データの備考に、歳入・歳出は新琴似図書館に含む、という趣旨の記述がある(元町・東札幌・厚別・西岡・清田・澄川・山の手・曙の各図書館)。新琴似図書館の備考には、地区図書館の全館分を含む、とある。館ごとの数字ではなく、新琴似図書館の欄が全館分をまとめて持っている。

したがって、この知識宇宙では歳入・歳出の列を取り込まない。取り込むときは、まとめて計上されていることを本文に書く。これは、属性表の列を機械的に移すと誤る例である。
