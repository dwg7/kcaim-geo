# /records/sapporo-authorized-roads
- status: verified
- updated: 2026-10-31

札幌市オープンデータの「札幌市認定路線網図」(2025年9月時点)から、札幌市内の主要道道を書き起こした。元データは、市内の認定道路(市道・道道)の線(Shapefile)で、図形も属性も令和7年(2025年)9月16日時点。国道は含まれない。線分は22,335本(うち12本はジオメトリが空)、ジオメトリのある路線は22,285本で、そのうち道道が33路線。

元データの属性は、路線区分(2 = 道道、3 = 市道)、区コード、路線番号、路線名、幅員(最小・最大)、供用区分(未供用だけ「未供用」と記載)。道道と、複数の区にまたがる道路の区コードは「00」。

ここでは、道道33路線のうち、路線名が「主要道道」で始まる11路線だけを書いた。一般道道(22路線)と市道は書いていない。

座標系は、元データが JGD2000 / 平面直角座標系 第XII系(EPSG:2454)。経緯度(GeoJSON の座標)へ変換した。JGD2000 と WGS84 の差は、ここでは無視できるものとして同一視した。

出典: 札幌市オープンデータ「[札幌市認定路線網図](https://ckan.pf-sapporo.jp/dataset/sapporo_authorized_road)」(CC BY 4.0。2026-10-31 参照)。元データには「完全性を保証しない」旨の免責がある。

# /rules/sapporo-road-geometry
- status: normative
- updated: 2026-10-31

このファイルの路線の線は、次の加工をしている。使うときはこの前提で扱うこと。

- 座標は、平面直角座標系第XII系(EPSG:2454)から経緯度へ変換した。
- 頂点を間引いた。方法は Ramer-Douglas-Peucker で、許容誤差は 10 m。元の頂点から間引いた線までの距離は、最大でも 10 m 以内に収まる。11路線で、元の3,498点が478点になった。
- 座標は小数点以下5桁(約1 m)に丸めた。

したがって、この線は、地図で路線の通りを示すためのもので、測量や経路案内、道路の幅や境界の根拠には使えない。街区スケールまで拡大すると、実際の道路とのずれが見える。

「認定路線」は、道路法に基づいて認定された道路であることを示す。現に通行できるかどうかとは別の情報である。
