# /records/nemuro-chashi-sites
- status: derived
- updated: 2026-10-31

Wikipedia 日本語版が挙げる、群の構成。所在は根室市内の地区名。座標は載っていない。

- 温根沼: チャルコロフイナ1号・2号チャシ(面崖式)
- 穂香: ポントマリ2号・3号チャシ、ニランケウシ1号〜3号チャシ、アッケシエト1号・2号チャシ(いずれも面崖式)
- 牧の内: シエナハウシチャシ、ノッカマフ1号・2号チャシ(面崖式)、コタンケシ1号・2号チャシ(丘先式)
- 豊里: サツコタンチャシ(丘先式)
- 温根元: コンブウシムイチャシ、トーサムポロ沼5号チャシ、トーサムポロR1西チャシ(面崖式)、ヒリカヲタチャシ、トーサムポロ沼1号チャシ、トーサムポロL2チャシ、ヲンネモトチャシ(丘先式)
- 落石: アフラモイチャシ(丘先式)
- 納沙布岬: ポンモイチャシ(丘先式)

形式は、海に面した崖を使う「面崖式」と、岬の先端を使う「丘先式」の2つ。遺構はいずれも空堀で、堀は方形に掘られている。造営は16〜18世紀とされる。名称には表記ゆれがある(ピリカヲタ/ヒリカヲタなど)。

二次資料(Wikipedia)の要約であり、一次の資料では裏を取っていない。
