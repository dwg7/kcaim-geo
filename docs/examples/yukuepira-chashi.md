# /places/yukuepira-chashi
- status: derived
- updated: 2026-10-31

北海道陸別町にある、アイヌのチャシ(砦・祭祀・会合などに使われたとされる土塁などの遺構)の史跡。利別川(としべつがわ)に臨む位置にある。

位置は Wikipedia 英語版が記す座標(43.464356, 143.735727)を用いた。現地では確認しておらず、史跡の範囲(面積・形状)でもなく、あくまで1点の概略位置である。したがって、この踏み跡は「出典から導いた位置」として `derived` に置く。現地で確認できたら `verified` に上げる。

# /records/yukuepira-chashi-reports

- updated: 2026-10-31

陸別町教育委員会は、史跡ユクエピラチャシ跡について複数の報告書を出している。奈良文化財研究所の「全国遺跡報告総覧」で確認できた範囲では次のとおり。

- 試掘調査報告書(第1次発掘調査、2000年)
- 平成14年度発掘調査概要報告書(2003年3月発行)
- 平成15年度発掘調査概要報告書
- 平成14〜20年度整備事業報告書(2009年発行、種別は「史跡-修理・整備」)

確認したのは書誌情報(書名・発行者・発行年)だけで、報告書の本文は読んでいない。発掘でわかった内容は、この踏み跡では扱わない。

出典: [奈良文化財研究所 全国遺跡報告総覧](https://sitereports.nabunken.go.jp/92420)(2026-10-31 参照)

# /interpretations/yukuepira-chashi-role
- status: derived
- updated: 2026-10-31

Wikipedia 英語版は、この遺跡の発掘で柵列の跡、柱穴、灰の層、鉄や骨の遺物が見つかり、15〜16世紀とされるシカの骨が大量に出たと述べる(約1万頭分とされる)。そこから、砦だけでなく、皮の交易などにも関わった場所だったのではないか、という解釈が示されている。

これは二次資料(Wikipedia)の要約から導いた解釈であり、一次の報告書で裏を取っていない。シカの骨の数や年代、交易との結びつきは、`/open-questions/yukuepira-chashi` で確認すべきこととして残す。

# /rules/historic-site-handling
- status: normative
- updated: 2026-10-31

史跡は文化財保護法の対象であり、現状を変える行為には許可が要る。この知識宇宙で史跡を扱うときは、次を守る。

- 遺構や遺物に手を触れない。採集しない。
- 立入や見学の可否は、現地の案内と管理者(自治体の教育委員会など)の指示に従う。
- 位置を `verified` にするための現地確認も、上の2点の範囲で行う。
